## Reporting a Vulnerability

If you discover a security vulnerability in **Data Curata**, please report it **privately** via email:

📧 **[security@data-curata.com](mailto:security@data-curata.com?subject=%5BSECURITY%5D%20Vulnerability%20report)**

Please **do not** open a public issue for security-related reports.

## What to Include

To help us address the issue quickly, please provide (when possible):

- A clear description of the vulnerability  
- Steps to reproduce the issue  
- Potential impact  
- Any relevant environment or version details  

## What Not to Do

Please avoid:

- Any illegal or unethical activity  
- Causing harm to systems, data, or other users  
- Taking advantage of the issue  
- Disclosing the issue to others before it has been resolved

## Our Commitment

- We will acknowledge your report within **7 days** and provide an initial evaluation
- We will keep you updated on our efforts to resolve it as quickly as possible
- We will not disclose any details before a fix is available  

Thank you for helping keep Data Curata secure.
