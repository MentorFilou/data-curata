## The Idea

1. Define a schema.

2. Collect & curate data.

3. Export in whatever format suits you next.

> Import them back later without losing a single field or entry.

---

## Who is this for?

When spreadsheets become too fragile and databases become too rigid, Data Curata provides structured, reusable datasets.

Typical use cases include:

- research datasets
- AI training datasets
- personal knowledge bases
- archival projects
- cataloging collections

## Quick Start

Installation and first-use documentation is on its way. In the meantime, clone the repo and use the commands below to get started locally.

Useful development commands:

```bash
pnpm dev             # dev server at localhost:5173
pnpm build           # production build
pnpm test            # vitest unit tests
pnpm test:e2e        # playwright smoke tests
pnpm lint            # eslint static code analysis
pnpm format          # prettier code style enforcement
```

For now, see `docs/SPEC.md` for the current source of truth.

## Our Story

Originally built to solve a personal need for simple structured data collection.
Later improved to be adaptable and useful for a broader range of scenarios.

Maintained through established tooling, active development, and continuous integration workflows.

The long-term goal is to create a reliable platform for data curation that prioritizes clarity and portability over unnecessary complexity and vendor lock-in.
